Use it in Excel

Paste this into any cell, where A2 holds the value you want encoded. Drag the fill handle down to barcode an entire column.

Tip: Excel’s IMAGE() supports PNG, JPEG, GIF, BMP and more — but not SVG. This tool outputs PNG, so it works everywhere, including Excel for the web.

API

URL parameters

The endpoint lives at /api/barcode. Only code is required.

  • code
    The text or number to encode. Required.
  • type
    Symbology name (default code128).
  • scale
    Image resolution, 1–10 (default 3).
  • height
    Bar height for linear barcodes (default 10).
  • includetext
    Set false to hide the human-readable text.
